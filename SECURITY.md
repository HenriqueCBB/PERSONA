# Segurança

- Este repositório **deve conter apenas código e dados sintéticos** (ver `AGENTS.md`).
- Visibilidade: o plano do projeto recomenda repositório **privado**. Se estiver público, trate tudo aqui como publicado.
- Achou dado real, credencial ou informação restrita? Não abra issue pública: avise o titular diretamente,
  remova do ramo e considere o dado exposto (rotacionar credencial; o histórico do git preserva o conteúdo).
- O gate `p0_gate.py` é uma camada técnica adicional, **não** substitui DLP, classificação institucional ou revisão humana.
